## 📊 Overview

**PlaceMate Pro** is an intelligent placement preparation platform that helps students assess their placement readiness, get personalized recommendations, and track their progress using AI-powered analytics.

### ✨ Features

- 🤖 **AI-Powered Predictions** - Smart placement probability scoring
- 📊 **Real-time Dashboard** - Interactive analytics and visualizations
- 💼 **Branch-wise Analysis** - Tailored recommendations for all branches
- 🎯 **Personalized Insights** - Strengths, improvements, and action items
- 🏢 **Company Recommendations** - Targeted company suggestions
- 💬 **AI Chat Assistant** - 24/7 placement guidance
- 📄 **PDF Reports** - Downloadable detailed reports
- 👨‍🏫 **Faculty Portal** - Admin analytics and data export

### 🏗️ Branches Supported

- Computer Science (CSE)
- Electronics (ECE)
- Mechanical Engineering
- Civil Engineering
- Electrical Engineering (EEE)
